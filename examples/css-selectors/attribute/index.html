Attribute selector

  • polyu.edu.hk — a[href^="https"], a[href*="polyu"]
  • report.pdf — a[href$=".pdf"]
  • report.PDF — the i flag makes it match as well
  • /notes.pdf — ends with .pdf, but does not start with https
  • a link with target — a[target] and a[target="_blank"]
  • a plain link — no attribute rule matches it

title="a yellow flower" — [title~="flower"]

lang="en-GB" — [lang|="en"] matches en, and en- anything
