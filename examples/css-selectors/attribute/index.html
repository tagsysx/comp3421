Attribute selector

The attribute is already written in the HTML, so this selector needs no extra hook — no class, no id. Three of the forms ask where in the value the text sits: the beginning, the end, or anywhere inside.

1 · Is the attribute there, and is it exactly this?

  • target="_blank" — a[target] matches it, and so does a[target="_blank"] (bold + red)
  • a link with no target — plain, because a[target] no longer matches

2 · Where in the value — begins with · ends with · contains

  • https://www.polyu.edu.hk/ — a[href^="https"] · a[href*="polyu"]
  • https://www.polyu.edu.hk/report.pdf — the same two, plus a[href$=".pdf"]
  • /notes.pdf — only a[href$=".pdf"]: it ends with .pdf, but it is not https and mentions no polyu
  • a link inside this page — none of the three matches it

3 · Any element, any attribute — not only a[href]

  • title="a yellow flower" — [title*="flower"] finds the word inside the sentence
  • — one rule, input[type^="date"], styles both
  • CSS — abbr[title] draws the dotted line under it

4 · The i flag — ignore case

  • https://www.polyu.edu.hk/report.PDF — only a[href$=".pdf" i] catches it, because of the i before the ]
