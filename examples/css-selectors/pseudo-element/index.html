Pseudo-elements

A pseudo-element styles a part of an element — a part you never wrote. The browser builds it, and it vanishes the moment the rule goes away. Five rules, five parts. They are element selectors, so every rule below reaches every paragraph or heading on this page, not just the one sitting under it.

1 — ::first-letter

p::first-letter { color: red; font-size: xx-large; }

You can use the ::first-letter pseudo-element to add a special effect to the first character of a text!

A drop cap. The letter is red and twice the size of the rest — and there is no <span> around it in the markup.

2 — ::first-line

p::first-line { color: red; font-variant: small-caps; }

You can use the ::first-line pseudo-element to add a special effect to the first line of a text. Some more text. And even more, and more, and more, and more, and more, and more, and more, and more, and more, and more, and more, and more.

"The first line" means whatever happens to be on the first line at this window width — narrow the window and the effect stops somewhere else. The paragraphs above already show both rules at once: red drop cap, then the rest of line one in small caps.

3 — ::before

h3::before { content: url("smiley.gif"); }

This is a heading

The ::before pseudo-element inserts content before the content of an element. The picture is the value of content, so it obeys the rules of inline content: it sits on the text baseline and the line box grows to make room for it.

4 — ::after

h3::after { content: url("smiley.gif"); }

This is a heading

The ::after pseudo-element inserts content after the content of an element. Both headings on this page now carry a smiley at each end — one rule, every <h3> in the document.
Neither of these two works without content. Write h3::before { color: red; } and nothing appears at all — not even an empty box. That is the quietest failure in the whole chapter.

5 — ::selection

::selection { color: red; background: yellow; }

Drag across this line. The text you highlight comes out red on yellow — on this line, and on every other paragraph on the page.

6 — What they cannot do

  • Not in the DOM. querySelector cannot find them, selecting the text does not copy them, and one cannot be nested inside another.
  • One of each, per element. An element can have a ::before and an ::after, and no more.
  • Decorative by default. Screen readers do not reliably announce generated text, and content: url() carries no text alternative. If a picture carries meaning, write a real <img> with a real alt.
