1 · Bookmarks — jumping within one page

A bookmark is just an id on any element, plus a link whose href starts with # and names that id. The browser scrolls the element into view — no JavaScript needed.

The five links in the grey bar above are all bookmarks. Click #bookmarks (you are probably already here), then try #images to skip straight past the reading below, or #bottom to land on the final paragraph.

Bookmarks are everywhere in real pages: table-of-contents sidebars, FAQ questions, "back to top" arrows, and long-form articles all rely on the same two ingredients — an id and an href="#…".

One rule to remember: an id must be unique in the page, so the browser always knows which single element you mean. Duplicate ids break bookmarks.

2 · Absolute URLs

An absolute URL contains the full web address, starting with the scheme. It works no matter where the current page lives: https://www.polyu.edu.hk points to the PolyU homepage whether you click it from Hong Kong or Helsinki.

Absolute URLs are the right choice when the target is on another site, or when you cannot rely on the folder structure staying the same. They are also what email links use: mailto: ray.yang@polyu.edu.hk opens the reader's email client.

You can open a link in a fresh tab by adding target="_blank" — PolyU in a new tab. Use it sparingly: forcing new tabs can annoy users, and the back button stops working the way they expect.

The alt attribute is what a screen reader speaks when it meets the image, and what a browser shows if the file cannot load. Try renaming the file to see the alt text appear. The width attribute keeps the image to a sensible size without CSS.

An image can itself be a link — just wrap it in an anchor. Click the small logo to visit the university website.

4 · Relative links

A relative link names the target by its position relative to the current file. Because it carries no scheme or host, it keeps working when the whole site moves to a new domain or a local folder.

Same folder: index.html. Parent folder: ../hello/index.html reaches the Hello world example in the sibling html/hello directory — the .. walks up one level first.

Relative links are the default for everything inside your own site: shorter to write, and immune to domain changes. Save absolute URLs for pages outside your site, like the MDN reference.
