A getter that computes, a static helper

get f is read like a property but computed on every read. fromF belongs to the class, not to an instance.

On the slide

class Temp {
  constructor(c) { this.c = c; }
  get f() { return this.c * 9 / 5 + 32; }
  static fromF(f) { return new Temp((f - 32) * 5 / 9); }
}
