A constructor with a method

One function, two objects. Read the last two lines: each instance keeps its own copy of len, because the arrow function is assigned inside the constructor.

On the slide

function Point(x, y) {
  this.x = x; this.y = y;
  this.len = () => Math.hypot(x, y);
}

const a = new Point(3, 4);
const b = new Point(6, 8);

What it prints




a.len === b.len 是 false —— 两个函数对象，不是共享的一份。把它挂到 Point.prototype 上才会变成 true，§02 的 class 就是自动替你做这件事。
