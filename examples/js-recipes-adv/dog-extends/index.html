Inherit and extend

extends sets two links, and super() must run before this is touched.

On the slide

class Animal {
  constructor(name) { this.name = name; }
  speak() { return this.name + " makes a sound"; }
}
class Dog extends Animal {
  constructor(name, breed) { super(name); this.breed = breed; }
  speak() { return super.speak() + " — woof"; }
}

What it prints




两个 true 是两条链：构造函数的 [[Prototype]] 指向 Animal，实例的原型指向 Animal.prototype。
