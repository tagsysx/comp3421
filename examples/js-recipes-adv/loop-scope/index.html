The loop bug, fixed — and not fixed

Two identical loops: let makes one binding per turn, var makes one for the whole function.

On the slide

for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}   // 0 1 2

What it prints




这就是两种写法唯一的差别：`let` per-iteration binding 是 ES6 为闭包专门加的规则。
