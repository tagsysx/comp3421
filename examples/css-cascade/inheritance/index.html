Inheritance

A property set on a parent is handed down to its children. A child that sets nothing of its own simply uses the parent's value.

Colour, font and size flow down

This heading declares nothing — it uses the parent's colour and font

So does this paragraph.

And this one is two levels down: the value keeps flowing to every descendant.

This one sets color: #d9534f itself, so the parent's colour stops here.

The box properties do not flow down

The parent has padding, a border and a background. This paragraph has none of them, and its own width is not shared either — box properties stay on the element you set them on.

That is why one color on a parent can colour a whole block, but one padding cannot.

Rule of thumb: the text properties inherit — colour, font, alignment, spacing between letters. The box properties do not — padding, margin, border, width, background.
