Three ways to add CSS

One declaration, three homes. The closer the style sits to the element, the stronger it is — and the harder it is to reuse.

1 · external — its own file

Only style.css styles this paragraph. This is the default: write it once, and every page that links the file gets it.

2 · embedded — a <style> block

Both style.css and the <style> block set this colour green and blue. Same selector, same weight — the block written later wins, so this is blue.

3 · inline — the style attribute

All three homes set this colour. The inline attribute sits on the element itself, so it wins — this is red. It also has to be repeated on every element you want it on.
