Named colours — all 148 of them

CSS lets you write a colour as an English word: color: tomato;. The words are called named colours, and this page is the whole list — 148 of them, every one shown as a card.

148 names in CSS 139 distinct colours 17 basic keywords 0 of them tell you what they look like

The spec is blunt about it: it is often hard to imagine what each name will look like (“hence the list below”), the names are not evenly spread through the colour space, and they are not even internally consistent. — CSS Color Module Level 4, §6.1

3 · Names that lie

green is not bright, lime is — green is #008000 and lime is #00FF00 — the everyday idea of “green” is lime.

greenlime

darkgray is lighter than gray — #A9A9A9 against #808080 — lightness 66% vs 50%. “dark” here means darker than white, not darker than gray.

graydarkgray

lightpink is darker than pink — #FFB6C1 against #FFC0CB — lightness 86% vs 88%.

pinklightpink

brown is a red, snow is a red — brown #A52A2A and snow #FFFAFA both sit at hue 0°.

brownsnow

nine names are the same colour twice — aqua = cyan and darkslategray = darkslategrey and dimgray = dimgrey and slategray = slategrey and lightslategray = lightslategrey and gray = grey and darkgray = darkgrey and lightgray = lightgrey and fuchsia = magenta. So 148 names are really 139 colours.

4 · Two keywords that are not in the list

Neither is a colour you can look up — both are defined separately in the spec:

transparent — fully transparent black; the same as rgba(0, 0, 0, 0).

currentcolor — whatever color currently is; it follows the text colour.

5 · How this page is written

Every card above is a <span> carrying its own style attribute — no <style> block, no classes, no selectors, no JavaScript. The card width, the border, the centring: the same declarations, written 148 times.

Want every card 20px wider? You now have 148 places to change. That is the problem selectors solve — the second half of Lecture 3.

Text colour on a card is not guessed: white or ink is picked per card by whichever contrasts more, so it stays readable on white and on navy alike.
