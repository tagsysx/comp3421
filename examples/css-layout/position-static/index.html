position: static — twenty boxes

Not one box on this page has position set, so every one of them is static. The browser places them itself: left to right along the line, and onto a new line when the next box is too wide for what is left.

Every width is a plain number of pixels, and nothing here sets a percentage, so the layout is worked out again whenever the page changes size. Drag the edge of the window and watch the rows change.

Which boxes share a line is decided by how much room the page gives them — every width here is fixed, so the answer changes whenever the window does. Nothing in the CSS has to be edited to see it: a wider window packs more boxes onto each line.

Box 3 also carries top: 24px; left: 24px;. Find it: it is butted right up against box 2, with no 24px shove to the right and no 24px drop. The browser read the two declarations and did nothing with them — that is what static does with the offsets.

Box 5 holds six boxes, laid out inside it by the very same rule: two share a line, the next one that will not fit wraps. Box 5's own width is written as 460px, so its inside does not change when the window does — the difference between a width you wrote and one the page gives you.
