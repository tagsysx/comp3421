position: static — ten boxes

Not one box on this page has position set, so every one of them is static. The browser places them itself — left to right along the line, and onto a new line when the next box is too wide for what is left.

Every width below is a plain number of pixels and nothing sets a percentage, on purpose: shrink or stretch this page and the layout has to be worked out again from scratch. Narrow the window a little and watch the rows change.

Which boxes share a line is decided by how much room the page gives them — the widths are all fixed, so the answer changes whenever the window does. Narrow it and the row of four becomes two rows of two; widen it and the four come back together. Whatever is left at the end of a line just stays empty.

Box 3 also carries top: 24px; left: 24px;. Find it: it is butted right up against box 2, no 24px shove to the right and no 24px drop. The browser read the two declarations and did nothing with them — that is what static does with the offsets.

Box 5 holds three boxes, laid out by the very same rule inside it: 5a and 5b share a line, 5c is too wide for what is left and wraps. Box 5 also grew taller to hold them, because nobody gave it a height.
