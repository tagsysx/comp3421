position: static

Every element is static until you say otherwise. It takes part in normal flow — top to bottom, left to right — and the four offsets (top, right, bottom, left) do nothing at all.

3 · The five values at a glance

valuewhat the offsets do
staticnothing — all four are ignored
relativenudge the box away from its own spot
absolutepin it to the nearest positioned ancestor
fixedpin it to the viewport
stickybehave as relative until it reaches the offset
