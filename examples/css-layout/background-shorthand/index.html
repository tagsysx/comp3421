the background shorthand

All three panels below ask for the same thing — img_mountains.jpg, a real photograph sitting next to this page, full-bleed over a dark blue. The declarations are printed underneath rather than on top, so the picture stays a picture.

longhand — five properties

background-color, background-image, background-position, background-size and background-repeat, one declaration each.

shorthand — the same thing, one line

background: #0e3f8c url("img_mountains.jpg") center / cover no-repeat; — nothing about the picture changes. Only the stylesheet got shorter.

and the one way that fails

The same shorthand without the / before the size. The declaration is invalid, so the browser drops it whole — no colour, no image. The dashed outline is the only thing left, because there is no paint at all.

The slash separates where the image sits from how big it is. Without it the declaration is thrown away whole — not just the size part.
