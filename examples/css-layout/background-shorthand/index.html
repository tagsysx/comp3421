The background shorthand

One declaration can set the colour, the image, the position, the size and the repeat together. It is the five properties you have just used, written as a single line.

Longhand

body { background-color: #ffffff; background-image: url("img_tree.png"); background-repeat: no-repeat; background-position: right top; }
Four lines, four properties — and each one can be changed and debugged on its own.

The same thing in one line

body { background: #ffffff url("img_tree.png") no-repeat right top; }
background: #ffffff url("img_tree.png") no-repeat right top;
Colour first, then the image, then repeat, then position. It does not matter if one of the parts is missing, as long as the ones that are there keep this order. Two warnings: the shorthand resets every background property you leave out, and the / between position and size is not optional — background: url(t.png) center / cover no-repeat;.
