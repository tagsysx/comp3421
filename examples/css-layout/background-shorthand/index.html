background-color, -image, -position, -size and -repeat, written out.

the short way

Nothing about the panel changes. Only the stylesheet got shorter.

and the one way that fails

no slash

This panel declares the same shorthand without the / before the size. The declaration is invalid, so the browser drops it — no colour, no image.

The slash separates where the image sits from how big it is. Without it the declaration is thrown away whole — not just the size part.
