Background — colour & image

The background is a box-model layer: painted under the content and the padding, and stopped at the border. The margin is never painted.

background-color

h1 { background-color: green; } div { background-color: lightblue; } p { background-color: yellow; }

green h1

lightblue div

yellow p

Any element can carry one, and each of these three gets its colour with nothing in the markup to say so. The lecture writes this on a bare h1 / div / p; style.css scopes it to the demo box below so the page's own own headings and panels is not affected too.

background-image

body { background-image: url("paper.gif"); }
background-image: url("paper.gif") — one small tile, repeated until the box is covered
By default the image repeats in both directions, so the file itself can be tiny. W3Schools puts this one on body; here it is on the demo box, so that you can see the edges of the thing being painted.
