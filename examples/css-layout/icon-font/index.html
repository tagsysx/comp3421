1 · One stylesheet, then a class name

An icon font is an ordinary font file whose glyphs are shapes instead of letters. Load the library once, and every icon in it is a class name on an inline element — <i> or <span>, it makes no difference. There is no image anywhere on this page.

five icons, five class names, zero picture files

2 · It is text, so the text properties apply

font-size

One glyph, three sizes. Nothing is redrawn or re-exported — the browser scales the outline.

color

The glyph takes the text colour, because it is text. Compare this with a picture icon, which needs one exported file per colour.

vertical-align

Download a file, or open it straight away.

It sits in the line like a letter, so it lines up with the words beside it without a single offset.

3 · What the font route costs

  • The whole font is one download. A full icon library is hundreds of kilobytes of glyphs, and the visitor fetches the lot for the three icons your page actually uses. Ship a subset of the font, or keep the library small on purpose.
  • A decorative icon is still a letter. A screen reader finds nothing useful in <i class="fa-solid fa-star">. Mark decoration with aria-hidden="true", and put a real text label next to any icon that carries meaning.
  • The class name belongs to the library. Font Awesome 4 wrote fa fa-cloud; version 6 writes fa-solid fa-cloud. Upgrading the library can mean editing every page that uses it.

Two ways to shrink the download, both worth knowing: a subset keeps only the glyphs you use, and an inline SVG sprite needs no font at all. The page that compares the three routes side by side is css-layout/icons.
