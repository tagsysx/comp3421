animation-direction

normal
alternate
reverse

All three run the same @keyframes grow. normal plays it forwards and restarts; alternate plays it backwards on every other pass, so there is no jump; reverse plays it backwards from the start.

animation-fill-mode — what happens before and after

fill-mode: none
fill-mode: forwards

Both slide once and stop after 1.5s. none snaps back to the starting style; forwards keeps the last keyframe — what you want for a "grow in once" entrance.
