animation-direction

normal
alternate
alternate-reverse
reverse

All four run the same @keyframes grow. normal plays it forwards and restarts; alternate plays it backwards on every other pass, so there is no jump; alternate-reverse starts on that backwards pass; reverse plays it backwards from the first frame.

animation-fill-mode — what happens before and after

fill-mode: none
fill-mode: backwards
fill-mode: forwards
fill-mode: both

Each bar waits 1s, slides once, then stops. While it waits, none and forwards sit at the bar's own style while backwards and both already show the first keyframe; once it has finished, none and backwards snap back and forwards and both keep the last keyframe.
