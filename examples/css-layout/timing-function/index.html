Same distance, same time — four curves

ease (default)
linear
cubic-bezier(.34, 1.56, .64, 1)
steps(5, jump-end)

Hover a track. Every dot covers the same distance in the same 1.2s — only the curve changes. The third overshoots and settles back; the fourth arrives in five jumps instead of sliding.

Where the curve comes from

The curve can be a keyword (ease, ease-in, ease-out, ease-in-out, linear), a cubic-bezier(x1, y1, x2, y2) you write yourself, or steps(n) for a stop-motion feel. A y value above 1 — like 1.56 above — is what makes the overshoot.
