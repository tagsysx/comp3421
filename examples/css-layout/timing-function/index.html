Same distance, same time — three curves

ease (default)
linear
steps(5, jump-end)

Hover a track. Every dot covers the same distance in the same 1.2s — only the curve changes. steps(5) arrives in five jumps instead of sliding.

Where the curve comes from

The curve is one of the keywords ease (the default), ease-in, ease-out, ease-in-out or linear — or steps(n) for a stop-motion feel.
