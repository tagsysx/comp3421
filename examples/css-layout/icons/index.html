1 · One icon, three ways

An icon can be a glyph from a font, a shape written into the page, or a picture file. All three put the same star on the screen — what differs is what happens when you resize it or change the colour of the words beside it.

An icon font <i class="fa-solid fa-star"></i>

One stylesheet, then a class name. The icon is a glyph, so font-size and color work on it.

An inline SVG <svg viewBox="0 0 24 24">…</svg>

The shape is part of the page, so CSS sizes it and fill: currentColor colours it.

A picture <img src="icon-star.png" width="24" alt="">

A file. The pixels are fixed when the file is made, and nothing in CSS changes them.

2 · Size — free for the first two, a second file for the third

an icon font at font-size: 96px

an inline SVG at width: 96px

a 24 px file drawn at 96px — soft

a 96 px file drawn at 96px — sharp

A picture has to be at least as large as the largest place you draw it: icon-star-24.png carries 24 rows of pixels and the browser stretches them to 96. The two cards on the right are the same icon — only the file behind them differs.

3 · Colour — the picture does not follow the text

the last two are two different files

Set color: #b93a33 on the paragraph and the first two go red by themselves: currentColor for the SVG, the text colour for the glyph. The third stays ink — it is a picture of a star, and no CSS declaration can repaint its pixels. The fourth is the file someone had to export a second time to make the row agree.

4 · Why so few

  • Sized for the biggest place you draw it. The file has to be as large as the largest use, or it goes soft — the pair above is that rule. Draw the icon at 96 somewhere and the 24 px file is wrong.
  • One file per colour. Ink on a light page, white on a dark header: two exports of the same shape. A glyph needed neither.
  • One request per file. A toolbar of twenty picture icons is twenty files — which is why a sprite sheet (icons.png, Lecture 4) and icon fonts exist.
  • Nothing inside it to change. You cannot fatten a stroke, fade one arm of the shape, or animate half the glyph: a picture is one finished image.

Three files, one icon — and that is the small end of the scale. A picture earns its place when the size is fixed and the number is small: a logo, a favicon, one decorative glyph on a card. For a set of icons that has to be sized, coloured and aligned with the words beside it, use the font or the SVG.

The one caveat: a picture only stops scaling when the file is a bitmap. An .svg file in an <img> scales to any size — but it still cannot take the text colour, and it is still one more file to fetch.
