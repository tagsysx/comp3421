width & height

a percentage is a share of the parent

width: 40%

width: 70%

width: 100%

max-width is a ceiling

width: 100%; max-width: 320px

Shrink the window and the second box stops growing at 320px — max-width wins whenever the two disagree.

height: auto follows the content

height: auto — this box is as tall as its text. Add a line and it grows, and nothing has to be recalculated by hand.

height: 96px — fixed, so longer text would spill out.
