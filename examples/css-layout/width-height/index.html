width & height

width and height set the size of the content area unless box-sizing says otherwise. auto — the default — means the browser works it out from the content.

A length, or a share of the parent

div { height: 200px; width: 50%; background-color: powderblue; }
height: 200px · width: 50% — measured against the box that contains it, so it scales with its parent
A percentage is a share of the containing block, not of the window. The lecture writes this on a bare div; style.css scopes it to the demo box below so the page's own panels is not affected too.

max-width caps a box

div.ex1 { width: 500px; margin: auto; border: 3px solid #73AD21; } div.ex2 { max-width: 500px; margin: auto; border: 3px solid #73AD21; }
width: 500px
max-width: 500px

Drag the window narrower than 500px and watch which of the two shrinks.

The first box holds its 500px whatever the window does — once the window is narrower, the page grows a horizontal scrollbar. The second simply gets narrower, which is what you want almost every time. min-height, min-width and max-height work the same way in the other direction.
