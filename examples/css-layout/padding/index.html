padding

Padding is the cushion between the content and the edge. It is inside the element, so the background paints it and a click on it still hits the element.

One side at a time

div { border: 1px solid black; background-color: lightblue; padding-top: 50px; padding-right: 30px; padding-bottom: 50px; padding-left: 80px; }
This div element has a top padding of 50px, a right padding of 30px, a bottom padding of 50px, and a left padding of 80px.
The light blue reaches the inside edge of the border — that is the padding being painted. The same four numbers can be written as one shorthand, padding: 50px 30px 50px 80px;, or cut to three values, padding: 50px 30px 50px;, because the top and the bottom are equal. The lecture writes this on a bare div; style.css scopes it to the demo box below so the page's own panels is not affected too.
