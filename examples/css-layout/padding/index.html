padding

Padding is the cushion between the content and the edge. It is inside the element, so the background paints it and a click on it still hits the element.

one to four numbers, clockwise from the top

padding: 24px

padding: 8px 32px

padding: 8px 32px 20px

padding: 4px 32px 20px 8px

one side at a time

padding-left: 48px

padding-top: 48px

Each box has a 2px edge so you can see the padding pushing the text away from it. Compare this with the margin page: padding is painted, margin never is.
