Border sides & the number order

Every border property can address one side at a time, or all four at once. When it takes several values they always run clockwise from the top.

One side at a time

p { border-top-style: dotted; border-right-style: solid; border-bottom-style: dotted; border-left-style: solid; }

dotted on top and bottom, solid on the left and right

Each of border-width, border-style and border-color has a -top, -right, -bottom and -left form. The lecture writes this on a bare p; style.css scopes it to the demo box below so the page's own paragraphs is not affected too.

Four colours, then four widths — the same order

p.colors { border-style: solid; border-color: red green blue yellow; } p.widths { border-style: solid; border-width: 2px 10px 4px 20px; }

border-color: red green blue yellow

border-width: 2px 10px 4px 20px

Read them clockwise from the top edge: top · right · bottom · left. One value covers all four sides, two mean vertical then horizontal, three mean top, the sides, then bottom, and four mean top, right, bottom, left. The same order drives padding and margin — learn it once.
