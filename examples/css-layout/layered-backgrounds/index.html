Layered backgrounds

One property, several images, separated by commas. The first image in the list is the one closest to you.

two images + a colour

A big circle, once, centred — over a tiled stripe — over the background colour.

the same two, swapped

Swap the order in the list and the stripes cover the circle. Nothing else changed.

Each layer answers its own list: background-position: center, 0 0; and background-repeat: no-repeat, repeat; are matched up with the images by position in the list — first value with the first image, and so on.
