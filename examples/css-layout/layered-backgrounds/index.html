Layered backgrounds

One property, several images, separated by commas. The first image in the list is the one closest to you — here img_tree.png (a transparent PNG) and img_flowers.jpg (a photograph), both real files next to this page.

Each layer answers its own list: background-position: center, 0 0; and background-repeat: no-repeat, repeat; are matched up with the images by position in the list — first value with the first image, and so on.
