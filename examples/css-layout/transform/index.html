Order matters — the list is applied right to left

translateX(20px) rotate(20deg)
rotate(20deg) translateX(20px)

The same two functions, swapped. The first travels along the page's X axis and then the whole box turns. The second turns first, so its 20px points along the axis it has just rotated onto — a diagonal.

Hover any box — the transform changes. Try editing the values.
