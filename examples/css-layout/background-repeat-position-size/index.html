Background — repeat, position, size

A background image tiles by default. background-repeat says how, background-position says where it is anchored, and background-size says how big it is.

repeat-x

body { background-image: url("gradient_bg.png"); background-repeat: repeat-x; }
background-repeat: repeat-x — one thin strip, repeated sideways only
repeat, the default, tiles both ways; repeat-x and repeat-y tile one way only; no-repeat draws it once. space and round fit a whole number of tiles in without cropping or overlapping them. W3Schools writes these on body; here they are on the demo boxes.

position: right top

body { background-image: url("img_tree.png"); background-repeat: no-repeat; background-position: right top; }
background-position: right top

The picture below is drawn from the top-right corner of this box.
background-position takes a pair — left / center / right, then top / center / bottom — or a pair of lengths or percentages. With no-repeat you can see exactly where it landed. background-attachment: fixed pins the image to the viewport so it stops moving when the page scrolls; scroll is the default.
