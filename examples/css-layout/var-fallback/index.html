Read a value: var(--name)

--brand was declared
--nope was never declared

The second pill asks for var(--nope, #d9534f). When a variable has never been declared, the fallback — everything after the comma — is used instead. Give no fallback and the declaration is thrown away, so the property keeps the value it would have had anyway.

Composable — one variable built from another

padding: calc(var(--gap) * 2)

A variable can be used inside another value, so one number can drive a padding, a gap and a width at the same time.
