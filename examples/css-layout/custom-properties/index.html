Declare on :root, use it later — the W3Schools two-variable page

Headline

Body text, in the colour the page was given.

Change the two values in :root and everything above changes with them. That is the whole point: the colour is written once and read everywhere.

Any value, not only a colour

A custom property can hold a length (--gap: 12px), a font stack, even a whole box-shadow. Names start with two dashes and are case-sensitive: --brand and --Brand are two different variables.
