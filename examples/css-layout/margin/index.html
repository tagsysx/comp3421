margin

Margin is the clear space outside the edge. Nothing is ever painted there — if you can see a colour, you are looking at padding.

one to four numbers, same order as padding

margin: 8px

margin: 8px 32px

margin: 8px 32px 24px

margin: 8px 32px 24px 4px

0 auto — the centring trick

margin: 0 auto — equal space on both sides

a negative margin pulls instead of pushes

margin-bottom: 0

margin-top: -12px — this box climbs up over the gap

A block only centres with margin: 0 auto if it has a width narrower than its parent — otherwise there is no space to share.
