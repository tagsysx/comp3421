margin

Margin is the clear space outside the edge. It is never painted — if you can see a colour, you are looking at padding.

Four numbers, clockwise from the top

p { margin: 100px 150px 100px 80px; }

margin: 100px 150px 100px 80px

100px above and below, 150px on the right, 80px on the left. The pale blue is the element itself; everything around it is margin. The lecture writes this on a bare p; style.css scopes it to the demo box below so the page's own paragraphs is not affected too.

margin: auto centres a block

div { width: 300px; margin: auto; border: 1px solid red; }
This div is centred: the leftover space is split equally left and right.
The element keeps the width you gave it and the remaining space in the parent is divided between the two margins. It only works on an element that has a width to begin with.

margin-left: inherit

div.container { border: 1px solid red; margin-left: 100px; } p.one { margin-left: inherit; }

This paragraph took its left margin from the div around it.

inherit forces a property to take the parent's computed value. Most of the box-model properties are not inherited by default — this is how you opt one in.
