One variable, three scopes

outside any component — reads :root

inside .card — .card re-declared it

a grandchild — still inherits from .card

Custom properties inherit like any other property. A child does not need to know where the value came from — it only needs var(--accent). Re-declaring --accent on one component re-paints that component and everything inside it, and nothing outside.

Scope it in a rule, not in every child
