A gradient is an image the browser draws — no file, sharp at any size. The angle is measured clockwise from the top, so 90deg runs left to right; the keywords to right and to bottom right say the same thing in words.

A repeating gradient is a pattern

repeating-linear-gradient(45deg, #fff 0 9px, #eef3fb 9px 18px) — the same idea, tiled.
