Backgrounds

The background is a layer of the box: colour, then image, then whatever you blend on top. It paints the content and the padding — never the margin.

background-color

A flat colour behind the content.

linear-gradient()

Two colours fading into each other.

radial-gradient()

A circle of colour spreading outward.

background-image + size + position

One real image file

img_tree.png — 200 × 358 pixels, transparent around the tree — is drawn once, anchored to the right, over a pale colour. The pale colour is still visible everywhere the file has no pixels.

the background shorthand

One line, five properties — background: #185fa5 url("img_tree.png") 0 0 / 34px 61px repeat;

layered backgrounds

Two images, one element

The tree is listed first, so it is in front — and it is transparent, which is how you can still see the photograph behind it.

mix-blend-mode

Every square is #185fa5, blended with the #ffc107 panel behind it — the mode alone decides what comes out. The captions stay outside the blended boxes, or they would be blended too.
