box-sizing

Both boxes below declare width: 240px, and both have the same padding and border. They are not the same width.

content-box — the default width: 240px is the content only. Padding and the edge are added on top: 240 + 20×2 + 6×2 = 292px.
border-box width: 240px is the whole box — content, padding and edge all fit inside. It stays 240px.

Most projects set * { box-sizing: border-box; } once at the top of the stylesheet, so a declared width is the width you get. This page does not, because the difference is the whole point of the demo.
