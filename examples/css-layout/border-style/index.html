border-style

Set a width and a colour but leave the style out and nothing is drawn at all — the style is what makes an edge appear. Here all ten values, 6px thick:

the flat ones

none

hidden

dotted

dashed

solid

double

the ones that carve the edge

groove

ridge

inset

outset

none and hidden both draw nothing. hidden only differs when two borders meet in a table — it loses the argument to its neighbour, none does not. The pale background on the first two is only there so you can see where the box is.
