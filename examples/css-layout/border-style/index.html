border-style

The one part you cannot leave out. Set a thickness and a colour with no style and no border is drawn at all — which is the quietest way to make a layout look wrong.

Ten values, one property

p.dotted { border-style: dotted; } p.dashed { border-style: dashed; } p.solid { border-style: solid; } p.double { border-style: double; } p.groove { border-style: groove; } p.ridge { border-style: ridge; } p.inset { border-style: inset; } p.outset { border-style: outset; } p.none { border-style: none; } p.hidden { border-style: hidden; } p.mix { border-style: dotted dashed solid double; }

four values, clockwise from the top:

dotted dashed solid double

dotted, dashed and solid are drawn by the browser in the border's own colour. double needs about 3px or more before the two lines separate. groove, ridge, inset and outset are 3D effects the browser draws for you. none and hidden both draw nothing — they differ only in how table borders collapse.
