1 · Loaders you can ship today

Every loader on this page is one @keyframes block plus animation: <name> <time> infinite — no JavaScript, no image file, no library. The animation line printed under each card is the one you copy.

Ring spinner

A round border with one side coloured. The default answer to “something is happening”.

animation: spin 0.8s linear infinite;
Counter-rotating rings

Two arcs turning opposite ways. Adding reverse to the inner one is the whole effect — no second keyframe anywhere.

animation: spin 0.9s linear infinite reverse;
Bouncing dots

One keyframe, three elements, a different delay on each. That is the whole wave — chat apps have been drawing it this way for twenty years.

animation: dot 1.2s ease-in-out infinite; /* delays 0.15s, 0.3s */
Eight-bar spinner

The classic operating-system one: eight bars on a single keyframe, each a step further along. A negative delay starts the loop already in motion, so nothing pops in when the page loads.

animation: bar 1s linear infinite; animation-delay: -0.5s;
Indeterminate progress bar

We do not know how long it will take, so the bar never fills. One element slides along the track while a second stretches and shrinks inside it.

animation: slide 1.5s ease-in-out infinite;
Skeleton card

The real thing, not a symbol: draw the shape of the content you are waiting for, then sweep a highlight across it. The grey blocks never move — only the light does.

animation: sweep 1.5s ease-in-out infinite;

2 · Ambient loops you already recognise

A loader announces an event. These instead run quietly in the background of pages you have used a hundred times.

Live dot

Two circles in the same place: a solid dot, and a copy of it that grows and fades away. Dashboards, chat presence, “recording”.

animation: ping 1.8s ease-out infinite;

Ticker

The text is printed twice and the track slides by exactly one copy, so the join is invisible and the loop never appears to end.

animation: marquee 9s linear infinite;
Equaliser

Five bars, one keyframe, and deliberately different durations and delays — so the pattern never lines up again and it reads as sound instead of as a machine.

animation: eq 0.8s ease-in-out infinite alternate;
Sync — turn, then rest

It finishes its turn at 55% of the cycle and then holds still. A loop that never rests reads as a fan, not as a refresh.

animation: turn-rest 1.8s ease-in-out infinite;

Alert nudge

Four quick stops inside less than a third of the cycle; the rest of the time it is perfectly still. That rest is what stops an alert becoming noise.

3 · What separates a loop from a good loop

linear

Constant speed, end to end. Correct for a rotation.

ease-in-out

Slows at both ends. Correct for anything that reverses.

The same travel, twice. Neither is better in itself — but put ease on a spinner and it stutters once per turn, and put linear on this pair and they look like machine parts.

  1. Stagger with animation-delay. One keyframe shared by several elements, a different delay on each: that is the entire difference between a row of dots and a wave. A negative value starts the loop already in motion.
  2. Let the loop rest. A keyframe may hold one value across two stops, which buys a pause inside the cycle. The sync icon and the alert above both spend most of their time standing still — that rest is what makes the movement read as a beat.
  3. Two elements beat one. The live dot is a dot plus a fading copy; the progress bar is a slider plus a stretcher. Nesting two simple animations is usually easier than writing one clever keyframe.
  4. Keep whole-second cycles in step. Parts that must stay aligned should share a duration that divides evenly — 0.9s against 0.9s stays married, 1s against 1.1s drifts apart in front of the reader.
  5. Animate transform and opacity. Those two the browser can move and fade without re-running the page layout. Change width, top or a colour instead and the page is laid out again on every frame of the loop. The skeleton card above is the honest exception — it repaints, and it is affordable only because it is small.

Nothing on this page asks whether the reader wants motion at all. The deck’s accessibility page adds the media query that switches all twelve of these loops off in a single rule.
