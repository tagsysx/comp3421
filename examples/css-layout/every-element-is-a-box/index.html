Every element is a box

This is an ordinary, multi-level document. Nothing on it was written for the demo. One rule, at the bottom of style.css, draws a line around every element in it.

the rule the levels a list an aside

One rule

* { border: 1px solid black; margin: 5px; }

The star is the universal selector — it matches every element in the document, so nothing has to be named one by one. The border is the line you can see; the margin is the 5 px of clear space that keeps two boxes from touching.

Which box is which

Read outwards from the text and you are reading the document tree. This paragraph sits in a <section>, inside <main>, inside <body>, inside <html>. Every one of them is a box, and every box is nested inside the one before it.

Boxes inside boxes

A list is the clearest place to see it: the <ul> is a box, and each <li> inside it is a box of its own.

  • html — the outermost box
  • body — the document itself
  • ul — the list
  • li — one row of it

An aside

An element you would not have thought of as a box is a box too. The edge does not care what the element is called or where it sits.

footer — the last box, made of the same four parts as the first.
