The five numbers, in one declaration

Every shadow on this page is built from the same five numbers. Read left to right: where the shadow sits, how soft its edge is, how big it is, and what colour it is.

0offset-x 10pxoffset-y 20pxblur −6pxspread rgba(0,0,0,.25)colour

The two offsets decide where the shadow goes; blur only softens its edge. A negative spread shrinks the shadow before it is blurred — that is what keeps a 20px blur from leaking out sideways and turning the box into fog. And the colour is rgba(0, 0, 0, α) rather than a grey, so whatever is underneath still shows through it.

Five recipes, and the moment each one is right

1 · Subtle elevation

A card at rest. The shadow is there to say “this is a surface”, not to be looked at — you should notice it only when it is missing.

box-shadow: 0 1px 3px rgba(0, 0, 0, .12);
Invoice
2 · Raised on hover

The same card, pointed at. Deepen the blur and push the offset down — a blur that grows while the offset stays put reads as a glow, not as height. Hover it.

box-shadow: 0 10px 20px -6px rgba(0, 0, 0, .25);
press Tab
3 · Focus ring

Spread with no blur and no offset draws a hard ring around the box — the one shadow here that is not about depth, and the only one that hangs off :focus-visible. If you take the browser's own ring away, put an equally visible one back.

box-shadow: 0 0 0 3px rgba(24, 95, 165, .35);
Search…
4 · Pressed in

inset flips the shadow to the inside of the box, so the surface reads as sunken instead of lifted. A search field or a well is its usual home.

box-shadow: inset 0 2px 6px rgba(0, 0, 0, .22);
Bougainvillea
5 · Text on a photo

White type over a photograph is only readable if the two are separated, and a photograph has bright patches wherever it likes. Hover the picture to take the shadow away and watch the caption melt into the flowers.

text-shadow: 0 1px 6px rgba(0, 0, 0, .6);

One dark shadow only

One hard shadow is the default thing to reach for, and the reason a lot of interfaces look flat and slightly dirty at the same time. The same card twice — look above the top edge of each one before you look below it.

Invoice
✗ One dark shadow

One blurred shadow with no offset puts the same grey halo on all four sides. Nothing tells the eye where the light is, so the card looks pasted on rather than lifted.

box-shadow: 0 0 18px rgba(0, 0, 0, .45);
Invoice
✓ Two or three soft ones

A tight contact shadow, a mid blur, and one wide and faint. Offsets all point the same way, so the three together read as a single object under a light from above.

box-shadow: 0 1px 2px rgba(0, 0, 0, .08),
  0 8px 16px -6px rgba(0, 0, 0, .18),
  0 20px 40px -12px rgba(0, 0, 0, .22);

Stacking is the whole trick: when a shadow looks wrong the fix is not “less shadow”, it is more of them — each softer and wider than the one before, all offset the same way. Keep the widest one modest, too: a blurred shadow is painted, not composited, so a very large blur on a long scrolling page costs real frame time.
