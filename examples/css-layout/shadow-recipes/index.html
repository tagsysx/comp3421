Five shadows you can copy

Subtle elevation
0 1px 3px rgba(0,0,0,.12)
Raised
0 12px 24px rgba(0,0,0,.18)
Focus ring
0 0 0 3px rgba(24,95,165,.35)
Pressed in
inset 0 2px 6px rgba(0,0,0,.22)

Two numbers set the offset, then the blur, then the colour — and 0 0 0 3px with no offset and no blur is a ring around the box, which is how a focus state is usually drawn.
