Box model

Every element is a box. This is the box that wraps it — read it from the inside out: content, padding, border, margin. One rule, four values.

The example

div { width: 300px; border: 25px solid green; padding: 25px; margin: 25px; }
This text is the content of the box. The width of 300px is the content alone — the padding, the border and the margin are added on top of it.
300px is the content. Add the padding (2 × 25) and the border (2 × 25) and the box is 400px wide; the margin is 25px more of clear space on every side, and it is never painted. The lecture writes this on a bare div; style.css scopes it to the demo box below so the page's own boxes is not affected too.

What each value does

content — where the text and the images appear.  padding — clears an area around the content, inside the edge; the background paints it.  border — goes around the padding and the content; it can be rounded.  margin — clears an area outside the edge; always transparent.
