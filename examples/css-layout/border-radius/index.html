50% on a square gives a circle; 999px is clamped to half the shortest side, so a wide box becomes a pill. Four values go clockwise from the top-left — 8px 24px 8px 24px rounds two opposite corners more than the other two.

the slash — a different radius across and down

50% 20% / 10% 40%

50% 50% 50% 50% / 60% 60% 40% 40%

100% 0 0 0

0 100% 0 0

Before the slash: the horizontal radius of each corner. After it: the vertical radius. Two numbers instead of eight covers all four corners.

one box, a circle corner then an ellipse corner

border-radius: 32px;

border-radius: 120px / 16px;

Both boxes are 288 x 96 px. The first corner is a quarter circle — one radius, the same across and down. The second reaches 120px across but only 16px down, so that corner is a quarter ellipse. Same box, same border, same background; only the pair of radii differs.

Nothing special is going on — each corner simply got its own pair of radii. The background and the border are clipped to the same curve, so the whole box changes shape, not just its outline.

and the same shapes with a border and an image

A border follows the curve, and so does a background image — which is why border-radius is the cheap way to make a badge or a blob.
