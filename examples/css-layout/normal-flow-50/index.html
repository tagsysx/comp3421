normal flow — fifty boxes

Fifty boxes, all exactly the same size, all just display: inline-block. Nothing tells any of them where to go.

The browser puts as many on a line as will fit, then starts a new line for the rest — that is normal flow, and it is what every element does until you change it.

Nothing in the CSS below changes when you resize the window; the boxes simply get a different amount of room to share. Count the boxes on the first line, drag the edge of the window, and count again.

The arithmetic is the whole rule: each box asks for 120px plus a 6px gap, so a line holds as many 126px steps as fit in the width of the page — and the leftover space at the end of a line is simply wasted. That is why the last line of the fifty is short.

This is also all a plain gallery of cards ever was: a fixed size, an inline-block, and enough of them to fill the page.
