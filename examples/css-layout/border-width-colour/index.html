The border shorthand takes one width — it applies to all four edges. For different sides use border-width: 10px 2px; (top/bottom · left/right) and set the style and colour alongside it. Writing border: 10px 2px solid is invalid and the whole declaration is dropped.

With no style the width does not even survive as a number: the second box declares border-width: 4px, and dev tools will report border-width: 0px. Nothing to draw, so there is nothing to measure.
