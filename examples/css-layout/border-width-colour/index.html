border-width & border-color

A border has three parts: style, width and colour. Neither of the last two does anything on its own.

border-color

p.one { border-style: solid; border-color: red; } p.two { border-style: solid; border-color: green; } p.three { border-style: dotted; border-color: blue; }

A solid red border

A solid green border

A dotted blue border

Any colour you can write anywhere else in CSS. With no border-style there is nothing for it to colour.

border-width

p.w1 { border-style: solid; border-width: 5px; } p.w2 { border-style: solid; border-width: medium; } p.w3 { border-style: dotted; border-width: 2px; } p.w4 { border-style: dotted; border-width: thick; }

5px

medium

2px

thick

A length in px, pt, cm or em — or one of the three keywords thin, medium and thick. The keywords are chosen by the browser, so a length is the predictable choice. Note where the width sits: outside the content, so 5px of border on both sides makes the box 10px wider than its declared width.
The width block uses .w1 to .w4 so that both blocks on this page can declare their own border without fighting over the same class.
