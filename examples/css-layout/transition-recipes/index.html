A transition needs a state change

Nothing eases on its own. Three things have to be true before a transition is the right tool: the element has a state it can move to, the property it moves has a halfway value, and the movement is the message. Miss any one of the three and you want a different tool. The recipes below are all the same shape — only the property and the trigger change.

1 · Four things that change an element's state

:hover
the pointer is over it
keyboard focus — press Tab
:active
the mouse button is down
a state you own — click it

Every recipe on this page is one of those four plus a property. If you cannot name the state, you cannot name the transition — that is the whole test.

2 · Twelve recipes, and the moment each one is right

Card
1 · Hover lift

A tile the user can click. The lift is the invitation — remove it and the tile stops looking clickable.

transition: transform 0.2s ease, box-shadow 0.2s ease;
2 · Button fill

The one action you want people to take. A fill that sweeps in says “this one” louder than a colour swap.

transition: background-size 0.28s ease;
Documentation
3 · Underline slide

Links in prose. The underline grows from the left, so the link reads as quiet text until you point at it.

transition: transform 0.22s ease;
photo
4 · Image zoom

A gallery thumbnail. The frame must not move — neighbours would reflow — so the picture inside it grows instead.

transition: transform 0.35s ease;
5 · Press down

The press itself needs an answer. Keep it short — a click that takes a quarter of a second to acknowledge feels broken.

transition: transform 0.1s ease;
6 · Focus ring

Accessibility, not decoration. Only keyboard users need it, so it hangs off :focus-visible — and it has to be unmistakable.

transition: box-shadow 0.18s ease;
Draft
7 · Colour shift

The change is a colour — a status, a tone, a selected tab. Nothing has to move for the meaning to land.

transition: background-color 0.3s ease, color 0.3s ease;
Harbour, 6pm
8 · Fade a caption in

The element is already laid out and you only want to reveal it. Fading avoids the layout jump that showing and hiding would cause.

transition: opacity 0.25s ease;
9 · Stagger a row

Several things change at once and you want them read in order. One delay per child, stepped with nth-child, buys the sequence for free.

span:nth-child(2) { transition-delay: 0.07s; }

10 · Nudge an arrow

A small directional cue: the arrow leans towards wherever the click takes you. No movement of the link itself.

transition: transform 0.2s ease;
11 · Pick a plan

A choice the user makes and can undo. Easing the border and background makes the selection feel like one state rather than a repaint.

transition: border-color 0.2s ease, background-color 0.2s ease;

Opened on request, closed again just as easily.

12 · Reveal a panel

A block the user asked to see. You cannot ease height: auto, so you ease max-height from 0 up to a value that is tall enough.

transition: max-height 0.3s ease;

3 · When a transition is the wrong tool

Same three conditions, checked again. Each pair below is the same interaction done twice: hover the left box and then the right one.

hover meSaved
✗ display: none → block

No halfway value, so it can only jump. The transition is ignored.

display: none;
display: block;
hover meSaved
✓ opacity + visibility

Opacity has a halfway value, and visibility can be delayed to the end. This is how a tooltip is supposed to arrive.

opacity: 0; visibility: hidden;

A panel that should grow when you ask it to.

✗ height: 0 → auto

auto is not a number, so there is nothing to count up to. It snaps open.

height: 0;
height: auto;

A panel that should grow when you ask it to.

✓ max-height

Give it a number to count up to — a little taller than the content will ever be.

max-height: 0;
max-height: 90px;

Three more times to reach for something else

  • It never stops. A spinner that turns forever has no state to change into, so a transition can never run it. That is a keyframe's job.
  • Nothing triggers it. “Play two seconds after the page loads” is not a state, so it is not a transition either.
  • transition: all. It eases properties you forgot you had — name yours instead. And keep routine interactions in the 150–250 ms range; a slow ease on a common click reads as lag, not polish.

Finally, the courtesy: if the reader has asked for less motion, give them less motion. One guard at the end of the sheet turns every ease above into an instant change.
