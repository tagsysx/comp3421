Stops are positions — put two at the same place for a hard edge

50% / 50%: a hard edge
20% · 60%: uneven bands

Every stop is a colour plus where it starts. Two stops at the same percentage leave nothing to blend, so the edge is sharp; move them apart and the blend comes back.

Alpha stops — a gradient that fades out

rgba() into transparent
#RRGGBBAA

The last stop can be transparent, which is how a photo is faded into the page instead of being covered with a solid strip.
