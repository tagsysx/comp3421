Outline

An outline is a line drawn around an element, outside the border, to make it stand out. It is not part of the box: it never changes the element's width or height.

A border grows the box — an outline does not

border: 6px offsetWidth grows to 256px
outline: 6px offsetWidth stays 244px

Both elements declare the same width: 220px. Dev tools will show the first one 12px wider — the border sits inside the box, the outline sits outside it.

outline-style — the same keywords as border-style

none dotted dashed solid double groove ridge

outline-offset — transparent space between the border and the outline

0 4px 12px -6px

A negative offset pulls the outline over the border — useful when the outline would otherwise collide with a neighbouring element.

The reason it exists — a focus ring

The browser draws a focus outline for free. Removing it without putting something else in its place leaves keyboard users with no idea where they are — it is one of the most common accessibility mistakes there is.

One ring, no sides

There is no outline-top or outline-left: an outline is a single ring around the whole element. The properties are outline-style, outline-color, outline-width, outline-offset, and the outline shorthand.
