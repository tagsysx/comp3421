outline

An outline is a line drawn around an element, outside the border, to make it stand out. It is not part of the box.

The example

p { border: 2px solid black; outline: #4CAF50 solid 10px; margin: auto; padding: 20px; text-align: center; }

This element has a 2px black border and a green outline with a width of 10px.

Ten pixels of green sit outside the two pixels of black. The lecture writes this on a bare p; style.css scopes it to the demo box below so the page's own paragraphs is not affected too.

Three things an outline is not

Not a border. A border is part of the box and pushes the neighbours away; an outline sits outside and may overlap them.  Not part of the size. The element's total width and height are unaffected, so a thick outline never reflows the page.  No sides. There is no outline-top — the whole ring is one value. outline-offset adds transparent space between the border and the outline, and a negative value pulls the outline in over the border.
