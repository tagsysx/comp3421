1 · What each query asks — and the answer right now

Every row below is a real @media block in style.css. Most of these recipes change something you can only see at one particular width, height, device or system setting, so instead of asking you to imagine it, this page puts the same question to the browser that the stylesheet asks and prints the answer. Drag the window, rotate the device, or switch the system to dark and watch the last column change.

The last column comes from window.matchMedia() in readout.js — the same text as the query, the same answer as the stylesheet. That is the whole point of a media query: it is a question with a yes-or-no answer, and CSS asks it again every time the environment changes.

Everything below reacts on its own — no script touches it. The eight blocks at the foot of style.css do the work, one per row of the table. Drag the window narrower and shorter, and read the three cards below.

Density

The mark beside this text is a 24 px file. On a screen of two dots per CSS pixel the query hands over the 96 px file instead, and the star stays sharp when it is magnified.

Settings

Dark mode and more contrast are not about the screen at all — they are what the reader asked the operating system for. Switch the system to dark and this page follows: one query, holding nothing but ordinary declarations with the other palette. Count how many there are — that repetition is exactly the job custom properties take over later in the lecture.

3 · The two you cannot see from here

  • Print the page. Press ⌘P (Ctrl+P elsewhere). The preview is the only place @media print is true: the nav bar and the banner above have gone, and the page is back on white.
  • Touch screens. The tooltip on the word Styles is for a mouse that can hover. @media (hover: none) takes it away on a touch device, where a tap can leave a hover style stuck open with no way to close it.

A media query never changes the markup. The same HTML arrives at every device and the query decides which blocks apply, so nothing here is a second mobile site — it is one page that answers the question differently.

readout.js is the exception that proves the rule: when the answer is needed in JavaScript rather than in CSS, window.matchMedia() asks the identical question and the change event fires when it flips.

The one recipe deliberately missing here is the one for a reader who asks the system for less motion: turning motion off means writing about animation, and the Animation section has an example of its own for that.
