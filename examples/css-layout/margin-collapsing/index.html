Margin collapsing

Two vertical margins that touch do not add up — the larger one wins.

20px below + 30px above = a 30px gap

margin-bottom: 20px

margin-top: 30px

Measure the gap in dev tools: 30px, not 50px.

a parent and its first child collapse too

a margin-top: 24px child inside a frame with no padding — the margin escapes the frame and pushes the whole frame down
the same child, but the frame has padding-top: 1px — now the margin has something to push against and stays inside

Look at the top edge of each frame: in the first one the child's margin has left the frame and become the frame's own, so the grey starts right at the child; in the second it stays put. Not a flex row on purpose — a flex container never collapses, which would hide the whole effect.

side by side they always add up

margin-right: 20px

margin-left: 30px

Horizontal margins never collapse: the space between these two is 50px. The two tags sit on one source line on purpose — a newline between inline-blocks is a whitespace character, and it would add 5px to the gap.
