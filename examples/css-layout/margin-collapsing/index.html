Margin collapsing

Top and bottom margins of elements stacked on each other collapse: the gap between them becomes the larger of the two, not the sum. Left and right margins never do this.

50px meets 20px

h1 { margin: 0 0 50px 0; } h2 { margin: 20px 0 0 0; }

Heading 2

The two margins make 70px on paper, but the gap you see is 50px — the larger one wins. Side by side the same 50 and 20 would add up to 70. The lecture writes this on a bare h1 / h2; style.css scopes it to the demo box below so the page's own own h1 title is not affected too.

Where it bites

Headings and paragraphs carry default top and bottom margins, so the space between two of them is one collapsed margin rather than two. A parent with no padding and no border lets its child's top margin escape through it as well — give the parent padding-top or overflow: hidden when you want it to stay inside.
