Normal flow

Left to right, top to bottom — and that is the whole of it. Every element is in normal flow until you change display, set position, or put it inside a flex or grid container.

Every box below has a border, so you can see where it starts and where it stops. The frame behind them is striped: any stripe you can see is page the boxes did not use.

1 · A block box takes a whole line

1 · width: auto — all of the line
2 · width: 100% — the same thing, written out
3 · width: 80%
4 · width: 55%
5 · width: 220px
6 · width: 120px

Six boxes, six lines. All six start at the same left edge, and not one of them moves up into the empty space beside a narrow neighbour — a block box owns its whole line however narrow it is drawn. That is why two block boxes never sit side by side, and why width alone never makes a row.

2 · A box with other boxes inside it

outer box · width: 440px

child A · width: auto → all of the outer box
child B · width: 62% of the outer box's inside

a box inside the outer box, with a child of its own

child C · width: 80% of this box — 80% again, a narrower box

The children are laid out inside their parent, by exactly the same rules, and the parent's height grows to fit them — nobody set a height. A percentage is measured against the parent's content box: child B is 62% of the outer box's inside, child C is 80% of the dashed box's inside. The same number two levels down gives a much narrower box.

Nine boxes with display: inline-block: they flow along the line instead of stacking down it, and a box that does not fit starts the next line. Same rule as section 1, running sideways — and the reason a row of cards used to mean floats and clearfixes.

4 · A margin moves everything that comes after it

no margin
margin: 28px 0 28px 64px
pushed down and right by the box above

The left margin moves this box in from the edge; the top margin moves it — and every box after it — down. Nothing is pulled up to fill the gap, on either side.

5 · What normal flow decides for you

questionanswer
which line is it on?the order it appears in the HTML
where on that line?left to right, in the writing direction
how wide is a block box?your width — or all of the parent
how tall is it?as tall as its own content, unless you set height
when does a line end?when the next box no longer fits

Try it in the editor. Give box 4 width: 100% and the stripes beside it disappear. Take the width off box 6 and it fills the line too. Now set display: inline-block on boxes 4 and 5 and watch them climb onto one line.
