background-repeat — the values

One image file, six values. The image is the same gradient_bg.png the lecture uses on the background-repeat page; only the one declaration changes.

repeat the default

div { background-image: url("gradient_bg.png"); background-repeat: repeat; }
Tiled in both directions. The image is 500 × 30, so the strip repeats down the box and the last row is clipped at the bottom edge.

repeat-x

div { background-image: url("gradient_bg.png"); background-repeat: repeat-x; }
Horizontally only: the file is exactly the shape of a header band, so one line of pixels covers a box this tall.

repeat-y

div { background-image: url("gradient_bg.png"); background-repeat: repeat-y; }
Vertically only — a column of the same tile, leaving the rest of the box empty.

no-repeat

div { background-image: url("gradient_bg.png"); background-repeat: no-repeat; }
One copy, at the top-left corner unless background-position says otherwise.

space

div { background-image: url("gradient_bg.png"); background-repeat: space; }
The same tile, repeated as often as it fits without being cut off: the first and last copies sit against the edges and the gap between them is spread evenly.

round

div { background-image: url("gradient_bg.png"); background-repeat: round; }
Repeated and stretched so a whole number of copies fills the box with no gaps and no clipping — compare the first tile with the one on the space box above.

initial and inherit

div { background-repeat: initial; /* repeat */ } div { background-repeat: inherit; /* whatever the parent was set to */ }
initial puts the property back to its default (repeat); inherit takes the parent's value instead of the property's own default. Neither of them is a pattern of its own.
